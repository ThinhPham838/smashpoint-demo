# SmashPoint PRO – Demo
React 18 + Vite + motion + three/R3F + Dexie (IndexedDB, không cần server DB).
```
npm install
npm run dev     # http://localhost:5173
npm run build   # ra thư mục dist/ để deploy (Vercel/Netlify)
```
Nâng cấp thật: thay `src/db.js` bằng Supabase (PostgreSQL) hoặc API Node + SQLite/PostgreSQL.
